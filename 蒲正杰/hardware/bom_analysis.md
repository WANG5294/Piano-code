# 硬件工程物料清单（BOM）分析

## 1. 开发板概述

本项目使用的硬件平台为 **ESP32-D0WD-V3** 开发板，集成 USB 转串口、电源管理、按键、LED、蜂鸣器、IMU 等功能模块。

## 2. 核心器件清单

| 功能模块       | 器件位号 | 型号 / 规格               | 说明                          |
|----------------|----------|---------------------------|-------------------------------|
| 微控制器       | U4       | ESP32-D0WD-V3             | 主控芯片，双核 Xtensa LX6     |
| Flash 存储     | U5       | ZB25VQ32（32 Mbit SPI）   | 程序与文件系统存储            |
| USB 转串口     | U2       | CP2102N                   | Micro-USB 转 UART             |
| 5 V 稳压       | U1       | AMS1085CM-5.0             | 5 V 电源稳压                  |
| 3.3 V 稳压     | U3       | AMS1085CM-3.3             | 3.3 V 电源稳压                |
| 蜂鸣器         | B1       | MLT-5020                  | PWM 驱动发声                  |
| 蜂鸣器驱动     | Q3       | MMSS8050-L-TP（NPN）      | 蜂鸣器电流驱动                |
| 绿色 LED       | LED2     | 0603 贴片 LED             | GPIO32，低电平点亮            |
| 红色 LED       | LED3     | 0603 贴片 LED             | GPIO33，低电平点亮            |
| 六轴 IMU       | U7       | MPU6050-YJLTY             | I2C 接口，扩展体感控制        |
| 电机驱动       | U6       | MX620B                    | 本项目不使用                  |
| 晶振           | X1       | 40 MHz                    | 主时钟源                      |

## 3. 数字钢琴使用资源

| 资源           | GPIO / 信号 | 用途说明                      |
|----------------|-------------|-------------------------------|
| BOOT 键        | GPIO0       | 下载/启动模式控制             |
| RST 复位键     | CHIP_PU     | 系统硬复位                    |
| do             | GPIO5       | 音符按键（内部上拉）          |
| re             | GPIO12      | 音符按键（内部上拉）          |
| mi             | GPIO14      | 音符按键（内部上拉）          |
| fa             | GPIO18      | 音符按键（内部上拉）          |
| sol            | GPIO19      | 音符按键（内部上拉）          |
| la             | GPIO21      | 音符按键（内部上拉）          |
| si             | GPIO22      | 音符按键（内部上拉）          |
| 低八度         | GPIO35      | 八度切换（输入 only，需外接上拉） |
| 高八度         | GPIO34      | 八度切换（输入 only，需外接上拉） |
| 绿色 LED       | GPIO32      | 状态/按键反馈                 |
| 红色 LED       | GPIO33      | 状态/按键反馈                 |
| 蜂鸣器         | GPIO25      | PWM 音频输出                  |
| MPU6050 SDA    | GPIO16      | I2C 数据线（扩展功能）        |
| MPU6050 SCL    | GPIO17      | I2C 时钟线（扩展功能）        |

## 4. 未使用资源

| 资源           | 原因                                  |
|----------------|---------------------------------------|
| 板载 KEY1/KEY2 | 已废弃，数字钢琴改用扩展排针 9 键     |
| 电机驱动 MX620B | GPIO26/GPIO27 等，本项目无电机控制需求 |
